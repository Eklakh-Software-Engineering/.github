## 🏗️ Engineering Principles
### Clean architecture

Systems should have clear responsibilities and maintainable boundaries.

### Reliability first

Applications should behave predictably under expected and unexpected conditions.

### Practical engineering

Technology choices should serve the problem rather than add unnecessary complexity.

### Testable systems

Software should be structured so that important behavior can be validated automatically.

### Maintainability matters

Readable code, clear interfaces, and sensible architecture reduce long-term engineering cost.
